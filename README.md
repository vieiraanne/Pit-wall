## 🔴 Sobre o Projeto

O **Pit Wall** é um site desenvolvido com HTML5 e CSS3, inspirado no universo da Fórmula 1 e no Grande Prêmio de São Paulo.

O projeto apresenta uma experiência temática de automobilismo, reunindo informações sobre pilotos, classificação, equipes e ingressos para a corrida no Autódromo de Interlagos.

## 🏎️ Funcionalidades

- **Grid de Pilotos:** apresentação de pilotos e suas respectivas equipes.
- **Classificação:** tabela com posições, vitórias e pontuação dos pilotos.
- **Busca e Filtros:** campos para pesquisar pilotos e selecionar equipes.
- **Ingressos:** apresentação dos setores disponíveis e seus preços.
- **Formulário de Reserva:** campos para preenchimento de dados pessoais, escolha de setor, quantidade de ingressos e envio de foto.
- **Design Responsivo:** adaptação para computadores, tablets e celulares.

## 🏁 Tecnologias Utilizadas

- HTML5 – Estruturação das páginas.
- CSS3 – Estilização, cores, layouts e responsividade.
- Google Fonts – Tipografia do projeto.

## 🏎️ Identidade Visual

O site utiliza uma estética inspirada nas pistas de corrida, com predominância das cores:

- 🔴 Vermelho: velocidade e adrenalina.
- ⚫ Preto: elegância e identidade automobilística.
- ⚪ Branco: contraste e organização.
- 🟠 Laranja: destaque para as equipes.

## 📂 Estrutura do Projeto

- `index.html` – Estrutura principal do site.
- `styles.css` – Estilos e personalização visual.
- `img/` – Imagens utilizadas no projeto.

## 🎯 Objetivo

Praticar os conhecimentos de desenvolvimento web, utilizando HTML e CSS para criar uma página temática, organizada, moderna e responsiva.
